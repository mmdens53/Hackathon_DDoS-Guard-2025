# Сканер и менеджер сетевых устройств

Веб-приложение для сканирования сетевых устройств и подключения к ним по различным протоколам.

## Возможности

- 🔍 Сканирование сети (ping, порты)
- 🖥️ SSH подключение через веб-терминал
- 👁️ VNC подключение через noVNC
- 🖼️ RDP подключение (генерация .rdp файлов)
- 📊 Определение ОС и доступных протоколов
